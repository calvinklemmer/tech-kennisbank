Java is een objectgeoriënteerde, platformonafhankelijke programmeertaal waarmee je applicaties, backendservices en enterprise-software kunt ontwikkelen.

Java draait via de Java Virtual Machine (JVM), waardoor dezelfde applicatie op verschillende besturingssystemen kan werken.

Belangrijkste kenmerken:

- Platformonafhankelijk: Java-applicaties draaien op Linux, Windows en macOS via de JVM.
- Objectgeoriënteerd: Software wordt opgebouwd uit classes en objecten.
- Sterke typering: Datatypes worden tijdens het compileren gecontroleerd.
- Garbage Collection: Automatisch geheugenbeheer.
- Multithreading: Ondersteuning voor parallelle en gelijktijdige verwerking.
- Enterprise: Veelgebruikt voor backendservices, API's en grote bedrijfsapplicaties.

### Belangrijke onderdelen

| Onderdeel | Functie                               |
| --------- | ------------------------------------- |
| Java      | Programmeertaal                       |
| JDK       | Ontwikkelkit met compiler en tools    |
| JVM       | Voert Java-bytecode uit               |
| Maven     | Build- en dependencymanagement        |
| `.java`   | Java-broncode                         |
| `.class`  | Gecompileerde Java-bytecode           |
| `.jar`    | Archief met Java-classes en resources |

### Voorbeeld

Java-broncode:

```
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}
```

Compileren en uitvoeren:

```
javac HelloWorld.java
java HelloWorld
```

Kort gezegd: Java is de programmeertaal, de JVM voert de gecompileerde code uit en Maven automatiseert het bouwen en verpakken van Java-software.
