Node.js is een open-source JavaScript-runtime waarmee je JavaScript buiten een webbrowser kunt uitvoeren, bijvoorbeeld op een server of ontwikkelmachine.

Node.js gebruikt de V8 JavaScript-engine van Google Chrome.

Belangrijkste functies:

- Backendontwikkeling: Webservers, REST API's en andere serverapplicaties bouwen.
- JavaScript uitvoeren: Scripts draaien via de commandline.
- Asynchrone verwerking: Efficiënt omgaan met veel gelijktijdige I/O-operaties.
- npm: Packages en dependencies installeren en beheren.
- Build tooling: Frontendprojecten bouwen met tools zoals Vite, Webpack en Storybook.
- Automatisering: Scripts uitvoeren voor builds, tests en CI/CD.

Voorbeeld:

```
node --version
npm --version
```

Een JavaScript-bestand uitvoeren:

```
node app.js
```

Kort gezegd: Node.js is de runtime die JavaScript-tools en -applicaties buiten de browser laat draaien. npm is de bijbehorende package manager.
