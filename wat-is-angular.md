Angular is een open-source frontendframework van Google voor het ontwikkelen van moderne, interactieve webapplicaties.

Angular gebruikt voornamelijk TypeScript en is vooral geschikt voor grotere, gestructureerde applicaties.

Belangrijkste functies:

- Component-based: Applicaties opbouwen uit herbruikbare UI-componenten.
- TypeScript: JavaScript met statische typecontrole.
- Data binding: Automatische synchronisatie tussen data en gebruikersinterface.
- Routing: Navigatie tussen verschillende pagina's.
- Dependency Injection: Gestructureerd beheren van afhankelijkheden tussen componenten en services.
- HTTP Client: Communicatie met backend-API's.
- Angular CLI: Projecten aanmaken, ontwikkelen, testen en bouwen.

### Technische samenhang

| Technologie | Functie                                |
| ----------- | -------------------------------------- |
| Node.js     | JavaScript-runtime voor ontwikkeltools |
| npm         | Package- en dependencymanagement       |
| Angular     | Frontendframework                      |
| Storybook   | UI-componenten ontwikkelen en testen   |
| Maven       | Java-builds en packaging               |

Kort gezegd: Angular is een framework waarmee je complete webapplicaties bouwt. Node.js en npm ondersteunen het ontwikkelproces, terwijl Angular-code uiteindelijk voornamelijk in de browser draait.
