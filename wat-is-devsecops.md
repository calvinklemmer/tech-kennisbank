DevSecOps (Development, Security & Operations) is een werkwijze waarbij informatiebeveiliging geïntegreerd wordt in het volledige softwareontwikkel- en beheerproces.

DevSecOps bouwt voort op DevOps en zorgt ervoor dat security niet pas achteraf, maar vanaf het begin wordt meegenomen (Shift Left Security).

Belangrijkste functies:

- Shift Left Security: Beveiligingscontroles vroeg in het ontwikkelproces uitvoeren.
- Security Automation: Beveiligingstests automatiseren binnen CI/CD-pipelines.
- Vulnerability Scanning: Kwetsbaarheden detecteren in broncode, dependencies en containerimages.
- SAST: Statische analyse van broncode op beveiligingsproblemen.
- DAST: Dynamische beveiligingstests op draaiende applicaties.
- Secrets Management: Wachtwoorden, tokens en certificaten veilig beheren.
- Compliance: Beveiligingsbeleid en controles automatisch afdwingen.

### Belangrijke onderdelen

| Onderdeel        | Functie                                            |
| ---------------- | -------------------------------------------------- |
| SAST             | Static Application Security Testing                |
| DAST             | Dynamic Application Security Testing               |
| SCA              | Software Composition Analysis van dependencies     |
| SBOM             | Software Bill of Materials met softwarecomponenten |
| Secrets Scanning | Detecteren van hardcoded wachtwoorden en tokens    |
| Policy as Code   | Beveiligingsregels automatisch afdwingen           |

### Verschil met DevOps

| DevOps                              | DevSecOps                                     |
| ----------------------------------- | --------------------------------------------- |
| Focus op ontwikkeling en beheer     | Integreert security in ontwikkeling en beheer |
| Automatiseert builds en deployments | Automatiseert ook beveiligingscontroles       |
| CI/CD                               | CI/CD met geïntegreerde securitytests         |
| Samenwerking tussen Dev en Ops      | Samenwerking tussen Dev, Sec en Ops           |

Kort gezegd: DevSecOps integreert beveiliging in het volledige DevOps-proces, zodat software continu en geautomatiseerd wordt ontwikkeld, getest, beveiligd en uitgerold.
