DevOps (Development & Operations) is een werkwijze waarbij softwareontwikkeling en IT-beheer nauw samenwerken om applicaties sneller, betrouwbaarder en efficiënter te ontwikkelen, testen en beheren.

DevOps combineert samenwerking, automatisering en continue verbetering.

Belangrijkste functies:

- Collaboration: Nauwe samenwerking tussen ontwikkelaars en beheerders.
- Continuous Integration (CI): Codewijzigingen automatisch bouwen en testen.
- Continuous Delivery (CD): Software automatisch voorbereiden voor deployment.
- Infrastructure as Code (IaC): Infrastructuur beheren via code.
- Automation: Handmatige beheer- en ontwikkeltaken automatiseren.
- Monitoring: Applicaties en infrastructuur continu bewaken.
- Continuous Feedback: Problemen en verbeterpunten terugkoppelen naar ontwikkeling.

### Belangrijke onderdelen

| Onderdeel            | Functie                                    |
| -------------------- | ------------------------------------------ |
| Git                  | Versiebeheer van broncode en configuraties |
| Jenkins              | Automatiseren van CI/CD-pipelines          |
| Docker               | Applicaties verpakken in containers        |
| Kubernetes           | Containers beheren en orkestreren          |
| Terraform            | Infrastructuur beheren als code            |
| Ansible              | Configuratiebeheer en automatisering       |
| Prometheus / Grafana | Monitoring en visualisatie                 |

### Hoe werkt DevOps?

1\. Development

Software ontwikkelen en wijzigingen vastleggen in Git

2\. Build & Test

Automatisch bouwen en testen via CI/CD

3\. Deployment

Applicaties gecontroleerd uitrollen

4\. Operations

Applicaties beheren en monitoren

5\. Feedback & Improvement

Resultaten gebruiken voor verdere ontwikkeling

### Verschil met DevSecOps

| DevOps                                  | DevSecOps                                          |
| --------------------------------------- | -------------------------------------------------- |
| Development + Operations                | Development + Security + Operations                |
| Focus op samenwerking en automatisering | Security expliciet geïntegreerd in het proces      |
| CI/CD en monitoring                     | CI/CD inclusief geautomatiseerde securitycontroles |

Kort gezegd: DevOps verbindt softwareontwikkeling en IT-beheer door samenwerking, automatisering en continue verbetering, zodat applicaties sneller en betrouwbaarder worden geleverd en beheerd.
