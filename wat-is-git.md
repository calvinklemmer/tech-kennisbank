Git is een open-source, gedistribueerd versiebeheersysteem waarmee je wijzigingen in broncode en configuratiebestanden kunt bijhouden en beheren.

Git wordt veel gebruikt bij softwareontwikkeling, DevOps en Infrastructure as Code (IaC).

Belangrijkste functies:

- Versiebeheer: Wijzigingen en eerdere versies bijhouden.
- Branching: Parallel aan verschillende versies of functionaliteiten werken.
- Merging: Wijzigingen uit verschillende branches samenvoegen.
- Samenwerking: Met meerdere ontwikkelaars aan dezelfde code werken.
- Rollback: Terugkeren naar eerdere versies.
- Traceerbaarheid: Vastleggen wie welke wijzigingen heeft doorgevoerd.

### Belangrijke onderdelen

| Onderdeel                    | Functie                                       |
| ---------------------------- | --------------------------------------------- |
| Repository                   | Opslag van broncode en wijzigingsgeschiedenis |
| Commit                       | Vastgelegde wijziging                         |
| Branch                       | Onafhankelijke ontwikkellijn                  |
| Merge                        | Samenvoegen van wijzigingen                   |
| Remote                       | Externe repository, bijvoorbeeld op GitLab    |
| Clone                        | Lokale kopie van een repository               |
| Pull Request / Merge Request | Voorstel om wijzigingen samen te voegen       |

### Veelgebruikte commando's

```
git clone <repository-url>
git status
git add .
git commit -m "Wijzigingen"
git pull
git push
git log --oneline
```
